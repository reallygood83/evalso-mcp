# Evalso MCP: 교사용 설치·사용 안내

학교 이름으로 학교알리미의 **교과별 평가계획**을 찾아 읽고, 교사가 확인한 성취기준과 학생의 실제 학습 모습을 바탕으로 교과 평어·세특 **초안**을 작성할 때 쓰는 도구입니다. MCP는 Codex나 Claude Code 같은 AI 도우미에 평가계획 조회 기능을 연결합니다. 평어 문장 자체는 연결한 AI 도우미가 쓰고, 교사가 사실관계와 기재 기준을 최종 검토합니다.

**가장 쉬운 방법:** 내 컴퓨터의 Codex 또는 Claude Code에 설치합니다. Evalso 키나 학교알리미 API 키가 필요 없습니다. **Grok Bot**은 실행하는 컴퓨터에서 Command 방식으로 연결하거나, 팀 공유용으로 HTTPS 서버를 배포할 수 있습니다. 아직 누구나 접속할 수 있는 Evalso 공용 MCP 주소는 제공하지 않습니다.

[![Grok Bot 설치 시작 버튼](https://img.shields.io/badge/Grok%20Bot-Install%20Evalso%20MCP-a6f4f5?style=for-the-badge&labelColor=171717)](https://reallygood83.github.io/evalso-mcp/)

버튼을 누르면 **설치 요청 문구를 복사하고 Grok Bot 소개·다운로드 페이지를 여는 안내 화면**으로 이동합니다. 이미 앱이 있다면 Bot 대화창에 붙여넣으세요. Bot에게 **Node.js·Git 확인, 누락 시 공식 사이트 설치 안내, 버전 재확인, MCP 등록**을 순서대로 요청합니다. 실제 플러그인 등록은 Bot에서 승인하거나 아래 명령을 설정 화면에 입력해야 합니다. 자동 설치를 약속하는 버튼은 아닙니다.

## 1. 설치 전 준비

1. 인터넷에 연결된 컴퓨터에 [Node.js](https://nodejs.org/ko/download) **20 이상**을 설치합니다. 새로 설치한다면 현재 **LTS**를 고르세요. 이미 설치했다면 건너뜁니다. 설치 후 터미널(Windows는 PowerShell)에서 `node -v`와 `npx -v`를 입력해 버전이 보이는지 확인합니다.
2. [Git](https://git-scm.com/downloads)을 설치하고 `git --version`으로 확인합니다. 아래 명령은 GitHub 저장소에서 프로그램을 내려받으므로 Git이 필요합니다.
3. [Codex](https://developers.openai.com/codex/cli) 또는 [Claude Code](https://code.claude.com/docs/en/overview) 중 **하나**를 설치하고 해당 서비스에 로그인합니다. 터미널에서 `codex --version` 또는 `claude --version`으로 확인합니다. 일반 ChatGPT·Claude 웹 채팅창에 아래 설치 명령을 붙여넣는 방식은 아닙니다.
4. 별도의 `EVALSO_MCP_TOKEN`이나 Upstage API 키는 필요 없습니다. 다만 Codex·Claude 등 **AI 도우미 자체의 이용 권한**은 필요합니다.

## 2. MCP 설치하기

터미널에 사용하는 도우미의 명령 **하나만** 붙여넣고 Enter를 누릅니다. 프로젝트 파일을 직접 내려받거나 수정할 필요는 없습니다.

**Codex 사용자**

```bash
codex mcp add evalso -- npx --yes github:reallygood83/evalso-mcp
```

**Claude Code 사용자**

```bash
claude mcp add --scope user evalso -- npx --yes github:reallygood83/evalso-mcp
```

Codex/Claude Code를 닫았다가 다시 엽니다. `codex mcp list` 또는 `claude mcp list`에서 `evalso`가 보이는지 확인하세요. 처음 사용할 때는 GitHub에서 필요한 프로그램을 설치하므로 잠시 걸릴 수 있습니다. **GitHub의 `npx` 설치 명령으로 도구 목록 조회까지 테스트했습니다.**

설치가 잘됐는지 AI 도우미에 다음처럼 말해보세요.

> evalso MCP로 `평촌초등학교`를 검색해줘. 같은 이름의 학교가 있으면 지역을 먼저 보여줘. 아직 평어는 만들지 마.

학교 이름·지역을 포함한 후보가 나오면 연결된 것입니다. 이름만 비슷한 학교를 임의로 선택하지 않아야 합니다.

## 3. 평가계획 찾기

1. **학교를 특정합니다.** 예: `경기도 안양시 평촌초등학교`. 동명이교가 나타나면 지역과 주소를 보고 해당 학교를 고릅니다.
2. **학년도·학기·학년·과목을 말합니다.** 예: `2026학년도 2학기, 6학년 국어`. 학교별 공시 상황에 따라 해당 학기 문서가 없을 수 있습니다. 다른 학기나 작년 문서를 허락 없이 대신 쓰지 않도록 요청하세요.
3. **문서를 고릅니다.** 학년별 HWP/HWPX/PDF/DOCX 등이 여러 개면 파일 이름을 보여달라고 한 뒤 해당 학년·학기 파일을 선택합니다. `학업성적관리규정` 같은 다른 문서를 평가계획으로 고르지 않게 확인합니다.
4. **기준을 확인합니다.** 선택한 문서에서 그 학년·과목의 성취기준을 **2개 이상**, 코드와 원문 문장으로 보여달라고 합니다. `evalso`는 최대 12,000자씩 문서를 읽으므로 긴 문서는 이어 읽어야 합니다. 학년·학기·과목이 문서에 명시되지 않으면 교사가 원문을 확인하세요.

한 번에 요청하려면:

> evalso로 안양 평촌초등학교의 2026학년도 2학기 6학년 국어 평가계획을 찾아줘. 학교나 파일이 여러 개면 먼저 선택을 물어봐. 해당 학년·학기·과목의 성취기준을 원문 코드와 문장 그대로 2개 이상 보여줘. 문서에 없는 내용은 추측하지 마.

## 4. 학생별 평어 초안 만들기

1. 표시된 성취기준 중 **그 학생을 평가할 기준 2개 이상**을 고릅니다. 문서에 기준이 하나뿐이라면 없는 기준을 지어내지 말고 그 사실을 확인합니다.
2. AI가 학생별 **각 기준의 성취 수준**(`상`, `중`, `하`, `노력 요함`)을 물으면 실제 평가에 맞게 답합니다. 모든 학생을 임의로 `상`으로 채우지 않습니다.
3. 실제 수업에서 본 행동·결과가 있다면 **이름과 학번을 빼고 한두 문장**으로 알려줍니다. 관찰 메모 없이 특정 발표·탐구·역할을 만들어서는 안 됩니다.
4. AI에게 `prepare_comment_guidance`로 **선택한 기준이 원문과 일치하는지 확인**한 뒤, 받은 작성 규칙과 교사가 말한 근거만 사용해 초안을 쓰게 합니다. 최종 문장의 과장·오류·분량은 교사가 검토합니다.

가상 대화 예시입니다. 아래 학생과 활동은 **설명용 가상 정보**이며 실제 평촌초 평가계획의 성취기준을 인용한 예가 아닙니다.

> **교사:** 방금 보여준 국어 성취기준 1번과 2번으로 학생 A를 써줘. 1번 `상`, 2번 `중`. 수업에서 글의 핵심 내용을 찾고 인물 행동의 근거 두 곳을 들어 이유를 설명했어. 관찰하지 않은 태도나 발표 경험은 넣지 마.
>
> **AI:** 두 기준의 코드·문장이 선택한 평가계획 원문과 일치하는지 먼저 확인하겠습니다. 확인되면 교사가 알려준 활동만 반영해 초안을 작성하겠습니다.
>
> **초안 형식 예:** 글의 핵심 내용을 파악하고 인물의 행동을 뒷받침하는 근거를 찾아 이유를 설명함. 제시된 단서를 활용하여 생각을 정리하고 설명하는 능력을 보임.

실제 결과에는 **원문에서 확인된 성취기준의 내용과 학생의 실제 수준**이 반영되어야 합니다. 이 예시 문장을 그대로 생활기록부에 입력하지 마세요. 여러 학생을 처리할 때도 학생별 수준과 근거를 각각 입력·검토합니다.

## Grok Bot에서 사용하기

Grok Bot의 사용자/팀 Bot은 **Custom MCP server**를 연결할 수 있습니다. 실행 환경에 따라 다음 중 하나를 고릅니다. 플러그인 추가 화면은 버전에 따라 다를 수 있으며, 실제 Grok Bot 화면에서 Evalso 연결에 성공했는지는 아직 검증하지 않았습니다.

먼저 위 **Grok Bot 설치 시작** 버튼을 눌러 요청 문구를 복사하고 **설치된 Bot 앱의 대화창**에 붙여넣으세요. Bot이 명령 실행 컴퓨터에 Node.js와 Git이 있는지 확인하고, 빠져 있다면 운영체제에 맞는 공식 설치 단계를 안내하도록 요청합니다. 그 컴퓨터에 접근할 수 없는 Bot이라면 실제로 설치됐다고 판단하지 마세요. Bot이 직접 플러그인 설정을 바꿀 수 없다면 아래 명령을 등록합니다.

**방법 A: Command (해당 컴퓨터에서 사용)**

Grok Bot이 MCP 명령을 실행하는 컴퓨터에 Node.js 20 이상, Git, `npx`가 있으면, Bot의 플러그인 설정에서 **Custom MCP server → Command**를 선택하고 `npx --yes github:reallygood83/evalso-mcp`를 입력합니다. 명령과 인자를 별도로 받는 화면이면 명령은 `npx`, 인자는 `--yes github:reallygood83/evalso-mcp`입니다. `EVALSO_MCP_TOKEN`은 필요 없습니다. Command 플러그인은 **대화가 실행되는 컴퓨터에서** 돌아가므로, 팀원이 다른 컴퓨터를 쓰면 그 컴퓨터의 실행 환경에서도 Node와 패키지 설치가 가능해야 합니다. 팀 전체가 한 서버로 사용하려면 아래 방법 B를 선택하세요.

**방법 B: Remote HTTPS (운영자·팀 공유용)**

이 저장소에는 Vercel 배포용 `api/mcp.ts`가 들어 있지만, 운영 중인 공용 서버를 제공하는 것은 아닙니다. 아래 단계는 **직접 서버를 운영할 사람**을 위한 것입니다. 서버가 없으면 URL만 입력해 연결할 수 없습니다.

1. Vercel에서 GitHub 저장소 `reallygood83/evalso-mcp`를 새 프로젝트로 가져옵니다. 배포 전 프로젝트의 환경변수 `EVALSO_MCP_TOKEN`을 **무작위 32자 이상**의 값으로 설정합니다. 예를 들어 로컬 터미널에서 `openssl rand -hex 32`로 만들 수 있습니다. 이 값은 GitHub나 채팅에 올리지 않습니다.
2. 배포에 성공하면 MCP 주소는 `https://<내-배포-도메인>/api/mcp`입니다. 브라우저 주소창에서 열어보는 GET 요청으로 연결 여부를 판단하지 마세요. 이 경로는 **인증된 MCP POST 요청만** 받습니다. 토큰 미설정은 503, 토큰이 없는 요청은 401입니다.
3. Grok Bot에서 자신이나 팀이 관리하는 Bot의 **플러그인/MCP 설정**에 들어가 **Custom MCP server → Remote HTTPS**를 선택합니다. 서버 주소에 위 HTTPS URL을 입력하고, 인증 설정이 Bearer 토큰·비밀 헤더를 지원하면 `Authorization: Bearer <같은 토큰>`을 설정합니다. 비밀값을 봇의 일반 지시문이나 공개 대화에 넣지 않습니다. 화면에서 필요한 인증 방식을 제공하지 않으면 현재 서버와 연결할 수 없습니다.
4. 연결 후 Bot에 `evalso 도구 네 개가 보이는지 확인하고 학교명만 검색해줘`라고 요청해 봅니다. 검색이 성공하면 위 **3~4단계 사용 흐름**을 그대로 따릅니다. 실제 Grok Bot 연결은 아직 이 저장소에서 실증하지 않았으므로, 운영 주소와 봇 화면에서 별도로 확인해야 합니다.

**토큰은 누가 입력하나요?** 개인 봇이나 개인 원격 클라이언트에는 각각 연결 설정이 필요합니다. 반면 **Grok Bot의 팀 봇**은 소유자가 원격 플러그인과 비밀값을 한 번 설정해 팀에 공유할 수 있어, 팀원은 토큰을 직접 입력하지 않고 사용할 수 있습니다. 그래도 서버에는 **공용 봇 자격 증명으로 요청**이 오므로, 팀 밖의 모든 교사에게 무제한 공개하는 방식과는 다릅니다. 개별 사용자별 사용량·권한·비용 통제는 별도 개발이 필요합니다. [Grok Bot Team Bots 공식 안내](https://docs.x.ai/grok-bot/team-bots)를 확인하세요.

Codex에서 자신의 원격 서버를 연결할 때는 서버 토큰을 **자신의 환경변수**에 보관하고 다음처럼 등록할 수도 있습니다.

```bash
codex mcp add evalso-remote --url https://<내-배포-도메인>/api/mcp --bearer-token-env-var EVALSO_MCP_TOKEN
```

## 자주 막히는 경우

| 증상 | 확인할 것 |
| --- | --- |
| `node`/`npx`를 찾을 수 없음 | Node.js 20 이상 설치 후 터미널을 다시 엽니다. |
| `git`을 찾을 수 없음 | Git을 설치하고 터미널을 다시 엽니다. |
| `evalso`가 도구 목록에 없음 | 설치 명령이 성공했는지 확인하고 Codex/Claude Code를 재시작합니다. |
| 같은 이름의 학교가 여러 개 | 지역·주소를 확인하고 그 학교를 고릅니다. |
| 원하는 평가계획이 없음 | 학년도·학기와 공시 파일을 다시 확인합니다. 다른 학기 문서를 자동으로 대체하지 않습니다. |
| `ocr_required` | 글자가 없는 스캔본입니다. 이 MCP는 OCR을 제공하지 않으므로 텍스트가 있는 평가계획 문서를 선택합니다. |
| Grok Bot 원격 접속 `401`/`503` | 각각 인증 헤더/서버의 `EVALSO_MCP_TOKEN` 설정을 확인합니다. |

서버가 학교알리미에서 가져오는 것은 **공개 평가계획**입니다. 학생 관찰기록은 MCP 도구로 전송하지 않지만, AI 도우미와의 대화 내용은 해당 모델 제공자의 처리 정책을 따릅니다. 학생 식별 정보를 입력하지 마세요. 학교알리미 페이지 형식이 변경되면 조회가 일시적으로 실패할 수 있습니다. 이 도구는 나이스에 자동 입력하지 않습니다.
