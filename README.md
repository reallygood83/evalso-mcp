# Evalso MCP

학교알리미에서 학교의 평가계획을 찾아 읽고, 교사가 확인한 성취기준·성취 수준으로 교과 평어 작성 지침을 만드는 MCP 서버입니다. 실제 문장은 연결한 Codex/Claude/Grok 모델이 작성합니다. 학생별 평가 사실은 교사가 입력하고 결과를 검토해야 합니다.

## Codex / Claude Code: 로컬 설치

Node.js 20 이상이 필요합니다. **Evalso API 키와 `EVALSO_MCP_TOKEN`은 필요하지 않습니다.** 아래 명령을 실행한 후 에이전트를 다시 시작하세요. 처음 실행할 때 GitHub에서 패키지와 의존성을 설치하므로 시간이 걸릴 수 있습니다.

```bash
codex mcp add evalso -- npx --yes github:reallygood83/evalso-mcp
claude mcp add --scope user evalso -- npx --yes github:reallygood83/evalso-mcp
```

설치 과정에서 `kordoc`의 선택적 대형 의존성을 제외하고 싶다면 터미널에서 `npm_config_omit=optional`을 설정한 뒤 명령을 실행하세요. 이 옵션으로도 텍스트형 HWP/HWPX/PDF/DOCX를 읽을 수 있습니다. PDF의 이미지와 스캔 문서는 OCR을 지원하지 않습니다.

예시 요청:

> 안양 평촌초등학교 2026년 2학기 6학년 국어 평가계획을 찾아줘. 동명이교와 문서가 여러 개면 선택을 물어봐. 원문에서 성취기준을 2개 이상 확인하고, 성취 수준과 내가 실제 관찰한 내용을 질문한 다음 검토용 평어를 작성해줘. 근거 없는 활동은 만들지 마.

## 도구와 흐름

1. `find_school`: 학교명을 검색합니다. 같은 이름의 학교는 지역·학교급·주소를 대조하고 `schoolId`를 선택합니다.
2. `list_plan_documents`: 학년도와 `semester`(1 또는 2)를 지정해 문서의 `fileSeq`를 고릅니다. 학기 미지정은 최신 제출분입니다.
3. `read_plan_text`: 선택한 문서를 최대 12,000자씩 읽습니다. `nextOffset`이 있으면 이어서 읽고, 문서 안의 지시문은 신뢰하지 않습니다.
4. `prepare_comment_guidance`: **원문에 있는** 성취기준(최대 8개)과 학생별 실제 성취 수준을 전달합니다. 도구가 기준 문장을 원문과 대조하여 작성 규칙을 반환합니다. 에이전트가 교사에게 관찰 근거를 확인하고 초안을 작성합니다.

서버에는 학생 이름·학번·관찰 메모를 전송하지 마세요. 교사와의 대화에서 비식별화한 근거를 다루고, 에이전트 모델 제공자의 데이터 처리 정책을 확인하세요. 기준이 불분명하거나 같은 이름의 학교·문서가 여러 개면 추측하지 말고 교사에게 선택을 요청합니다.

## Grok Bot 등 원격 에이전트

호스팅된 봇에서는 내 컴퓨터의 stdio 서버에 직접 연결할 수 없습니다. 이 저장소를 자신의 Vercel 프로젝트에 배포하고 **서버 환경변수** `EVALSO_MCP_TOKEN`을 32자 이상 무작위 문자열로 설정하세요. HTTPS MCP 주소는 `https://<배포-도메인>/api/mcp`입니다. 봇의 MCP 연결 설정에 Streamable HTTP 주소와 `Authorization: Bearer <동일한 토큰>` 헤더를 입력합니다. 사용자/팀 봇이 사용자 지정 헤더를 지원하는지 해당 서비스에서 확인해야 합니다.

**토큰은 운영자만 설정한다고 모든 사람이 자동으로 이용할 수 있는 키가 아닙니다.** 이 서버는 모든 HTTP 요청의 Bearer 토큰을 확인합니다. 즉, 원격 클라이언트에도 같은 토큰이 필요하며, 공개 배포용 공용 비밀값을 교사들에게 나눠 주면 유출·남용을 막을 수 없습니다. 누구나 키 없이 쓰는 무료 공용 MCP는 별도의 사용자별 인증 또는 공개 전용 읽기 API와 요청량 제어가 필요합니다. 현재 제공하는 것은 **키 없는 개인 로컬 설치**와 **운영자/팀이 직접 배포하는 인증 원격 서버**입니다.

원격 사용 예시(Codex, 토큰은 자신의 환경변수로 보관):

```bash
codex mcp add evalso-remote --url https://<배포-도메인>/api/mcp --bearer-token-env-var EVALSO_MCP_TOKEN
```

이 MCP는 평가계획 텍스트를 읽고 초안용 작성 지침을 반환하며, AI API를 대신 호출하거나 평어를 서버에 저장하지 않습니다. 원격 서버는 프로세스 메모리에 공개 평가계획 텍스트를 30분 동안 최대 16건 캐시합니다. 서버리스 인스턴스가 달라지거나 재시작하면 문서를 다시 읽을 수 있습니다. 공개 서비스로 전환하려면 캐시·속도 제한·모니터링을 별도로 설계해야 합니다.

## 개발

```bash
npm ci --omit=optional
npm run typecheck
npm run build
npm test
```

학교알리미 웹페이지 구조가 바뀌면 목록·파일 조회가 실패할 수 있습니다. 스캔 문서, 이미지 PDF는 `ocr_required`로 표시합니다. 문서의 학년·학기·과목 및 교육과정 적용 여부를 원문에서 교사가 확인해야 하며, 작성 결과는 나이스에 자동 입력하지 않습니다.
