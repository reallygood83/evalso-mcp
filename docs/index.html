Grok Bot에 Evalso 연결하기

학교 이름으로 평가계획을 찾아 평어 초안을 만드는 도구입니다. 버튼을 누르면 설치 요청 문구를 복사하고 Grok Bot 소개·다운로드 페이지를 엽니다. 이미 앱을 사용 중이라면 Bot 대화창에 문구를 붙여넣으세요.

Grok Bot 다운로드 안내

이 버튼이 MCP를 자동 설치하지는 않습니다. Grok Bot이 설치를 지원하지 않는다면 아래 명령을 플러그인 설정에 직접 입력하세요.

Bot이 설치 준비부터 안내합니다

  1. 설치된 Grok Bot 앱의 대화창에 요청 문구를 붙여넣습니다. Bot이 명령 실행 환경에서 node -v, npx -v, git --version을 확인하도록 요청합니다.
  2. 빠진 프로그램이 있으면 Bot에게 운영체제에 맞는 공식 설치 페이지와 순서를 안내받습니다. 설치 후 새 터미널에서 버전을 다시 확인합니다. Bot이 명령을 직접 실행하지 못하면 교사가 확인 결과를 알려줍니다.
  3. 준비가 끝나면 Bot에서 MCP 등록을 요청합니다. 직접 추가할 수 없다면 Plugins → Custom MCP server → Command에 명령 npx, 인자 --yes github:reallygood83/evalso-mcp를 넣습니다.
  4. 연결 후 evalso로 평촌초등학교를 검색해줘라고 말해 학교 후보가 표시되는지 확인합니다.

확인할 곳은 교사의 휴대전화가 아니라 Bot이 MCP 명령을 실행할 컴퓨터입니다. Node.js 최소 20 이상과 Git, 인터넷 연결이 필요합니다. 새로 설치한다면 Node.js의 현재 LTS를 권합니다. 이 Command 방식에는 EVALSO_MCP_TOKEN이 필요하지 않습니다.
