01 · 준비

설치 전 준비

  1. Node.js 20 이상을 설치하세요. 새로 설치한다면 LTS를 선택합니다. 설치 후 터미널(Windows는 PowerShell)을 새로 열고 node -v, npx -v로 확인하세요.
  2. Codex, Claude Code, Hermes Agent 중 사용할 도우미를 설치하고 모델 로그인을 마치세요.
  3. 일반 웹 채팅창이 아닌, 도우미를 실행하는 컴퓨터의 터미널에 아래 명령을 입력합니다. npm 방식에는 Git이나 npm login이 필요 없습니다.

02 · 연결

도우미에 연결하기

사용하는 도우미 하나를 선택하세요. 첫 실행에는 패키지 다운로드로 시간이 걸릴 수 있습니다.

CodexClaude CodeHermes Agent

Codex에 연결

Codex CLI가 설치된 터미널에서 실행하세요.

codex mcp add evalso -- npx --yes evalso-mcp@0.1.0

codex mcp get evalso로 등록을 확인하고 새 대화를 여세요. Codex 앱에서도 같은 사용자 설정의 MCP를 확인한 뒤 사용합니다.

Claude Code에 연결

Claude Code가 설치된 터미널에서 실행하세요. 모든 프로젝트에서 쓸 수 있는 사용자 범위로 등록됩니다.

claude mcp add --scope user evalso -- npx --yes evalso-mcp@0.1.0

claude mcp get evalso에서 Connected를 확인하세요. 새 대화의 /mcp에서도 도구를 확인할 수 있습니다. Claude Code 로그인은 별도로 필요하며, Claude 웹·Desktop 앱용 설치 명령은 아닙니다.

Hermes Agent에 연결

사용할 활성 프로필의 터미널에서 실행하세요. 첫 다운로드를 기다리도록 180초를 지정합니다.

hermes mcp add evalso --connect-timeout 180 --command npx --args --yes evalso-mcp@0.1.0

도구 4개 활성화 질문에 y를 입력합니다. hermes mcp test evalso로 확인한 뒤 새 대화를 열거나 /reload-mcp를 실행하세요. 다른 프로필에는 별도로 등록해야 합니다.

Windows에서 npx를 찾지 못하나요?

먼저 터미널을 다시 열고 npx -v를 확인하세요. 명령 파일 실행 오류가 계속되면 실행 명령을 cmd /c npx --yes evalso-mcp@0.1.0로 감싸 연결하는 방법을 사용할 수 있습니다. Windows 실기기 검증은 아직 완료하지 않았습니다.

03 · 작성

평가계획에서 평어 초안까지

  1. 학교 확인

    학교 이름을 검색하고 지역·주소로 정확한 학교를 고릅니다. 동명 학교를 임의로 선택하지 않습니다.

  2. 평가계획 선택

    연도·학년·학기를 확인하고 문서를 선택합니다. 원하는 연도의 자료가 없으면 다른 연도로 바꾸기 전에 확인합니다.

  3. 성취기준 조합

    문서에서 확인한 기준 2개 이상을 조합하고, 학생의 실제 성취 수준과 학습 모습을 간단히 알려주세요. 도우미가 필요한 내용부터 질문하도록 요청할 수 있습니다.

  4. 초안 검토

    MCP가 제공한 자료와 작성 안내를 바탕으로 연결한 AI가 초안을 씁니다. 교사가 사실관계와 기재 기준을 확인한 뒤 사용하세요.

학생 이름·학번 대신 익명 번호를 사용하세요. 대화에 입력한 내용은 연결한 AI 서비스의 데이터 처리 정책을 따릅니다. 실제 관찰하지 않은 내용을 사실처럼 쓰지 마세요.

04 · 확인

자주 묻는 질문

정말 무료인가요? API 키가 필요한가요?

Evalso MCP는 MIT 라이선스로 무료 제공됩니다. 로컬 연결에는 Evalso 토큰, 학교알리미 키, Upstage 키가 필요 없습니다. 연결하는 AI 도우미의 구독·모델 비용은 별도입니다.

MCP가 평어를 직접 생성하나요?

MCP의 도구는 find_school, list_plan_documents, read_plan_text, prepare_comment_guidance 네 가지입니다. 학교 검색·문서 읽기·성취기준 확인·작성 안내를 제공하며 문장 생성은 연결한 AI가 맡습니다. 나이스 자동 입력이나 교육과정 공식 코드의 완전한 검증을 제공하지는 않습니다.

학교 검색이나 문서 읽기가 안 되면요?

학교알리미의 응답 지연이나 접속 환경을 확인하세요. 해외 실행 환경의 연결은 보장하지 않습니다. 이미지로 된 문서에는 OCR이 필요하지만 현재 MCP 자체 OCR은 지원하지 않습니다. 내용을 확인하지 못한 문서로 초안을 만들지 마세요.

Grok Bot에도 연결할 수 있나요?

해당 봇이 로컬 stdio MCP 실행을 지원해야 합니다. 지원한다면 실행 명령 npx, 인수 --yes evalso-mcp@0.1.0을 등록합니다. 봇별 실제 동작은 검증하지 않았으며 공개 HTTPS MCP 주소는 제공하지 않습니다. GitHub 링크를 보내는 것만으로 설치되지는 않습니다.

Git 패키지 설치가 차단됐다고 나와요.

위의 npm 레지스트리 명령을 사용하세요. npx github:... 방식이나 보안 정책 해제는 필요 없습니다. 소스 설치가 필요한 경우에만 README의 대체 설치 방법을 확인하세요.
