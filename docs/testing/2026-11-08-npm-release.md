- 게시 전 타입 검사, 빌드, 테스트 4개가 통과했다. 패키지에는 배포 코드, README, LICENSE, package.json만 포함된다.

## 일반 사용자 신규 설치

프로젝트 밖 `/tmp`에서 새 npm 캐시와 빈 사용자 설정(`/dev/null`)으로 아래 명령을 실행했다. 게시자 npm 로그인 정보, Upstage 키, 학교알리미 키, Evalso 토큰은 전달하지 않았다.

```bash
npx --yes evalso-mcp@0.1.0
```

MCP 클라이언트가 실행 파일과 연결하여 도구 4개를 발견했고, `find_school`로 평촌초등학교를 검색해 안양시 동안구 학교를 포함한 실제 후보를 받았다. CLI를 브라우저에서 여는 방식이 아니라 stdio MCP 클라이언트로 검증했다.

## Hermes 활성 프로필

기존 `default` 프로필의 Evalso 연결만 로컬 경로에서 npm 패키지로 전환했다. 모델과 다른 프로필은 변경하지 않았다.

```bash
hermes mcp add evalso --connect-timeout 180 --command npx --args --yes evalso-mcp@0.1.0
hermes mcp test evalso
```

재등록 시 도구 4개 연결 성공. 별도 연결 검사에서도 약 772ms에 연결되고 도구 4개가 발견됐다. Git 패키지 제한을 해제하지 않았다. 기존 대화에서는 `/reload-mcp`를 실행하거나 새 대화를 열면 된다.

문서: `2026학년도 평촌초 2학기 6학년 교수학습 및 평가계획.hwpx`, `fileSeq=5`.

선택한 기준과 합성 학생의 가정 수준:

- `[6-국03-06]` 작가의 의도를 생각하며 작품을 읽는다. **상**.
- `[6국01-03]` 글이나 자료를 읽고 내용의 타당성과 표현의 적절성을 평가한다. **중**.

첫 코드의 특이한 하이픈도 원문 그대로 유지했다. 선택 문서와의 대조를 통과한 것이며 국가 교육과정 공식 코드의 정확성을 별도로 인증한 것은 아니다.

Hermes가 자신의 모델로 두 기준을 조합해 작성한 **합성 초안, 공백 포함 210자**:

> 작품에서 반복하거나 강조한 표현의 의미를 살펴 작가의 의도를 구체적으로 짐작할 수 있음. 작가가 전하려는 생각을 자신의 삶과 관련지어 이해하고 글로 나타낼 수 있음. 글이나 자료의 주장과 이를 뒷받침하는 이유 및 근거를 파악하여 내용의 타당성을 기본적인 수준에서 판단할 수 있음. 표현이 전달하려는 내용에 알맞은지 살펴보며, 내용과 표현을 함께 고려하여 글을 이해할 수 있음.

전체 실행 약 37초. Upstage API는 사용하지 않았다. 실제 학생의 관찰·활동·태도·성장 사례는 입력하거나 확인하지 않았으므로 실제 생기부에 그대로 사용해서는 안 된다. 교사의 실제 성취 확인과 문장 검토가 필요하다.

## 검증 범위

npm 공개 게시, 인증 없는 신규 설치와 검색, 활성 Hermes npm 연결, 실제 평가계획 조회, 두 기준 대조와 합성 초안 생성을 확인했다. Windows, Grok Bot 실제 연결, 해외 네트워크, OCR 및 중·고등학교 실문서는 별도 검증이 필요하다. 전체 대화와 계정 인증 정보는 저장소에 게시하지 않았다.
