## Hermes 생성 초안

> 작가의 의도를 생각하며 작품을 읽고, 작품에 담긴 의미와 작가가 전하려는 바를 깊이 있게 이해할 수 있음. 작품의 표현과 내용을 연결하여 작가의 의도를 타당하게 짐작할 수 있음. 글이나 자료의 내용을 파악하고 주장과 근거를 살펴 내용의 타당성을 기본적인 수준에서 판단할 수 있음. 표현이 전달하려는 내용에 알맞은지 살펴보며, 내용과 표현을 구분하여 평가하는 방법을 이해함.

이는 실제 학생 관찰에 근거하지 않은 **합성 테스트용 초안**이다. 구체적인 발표·활동·성장 일화는 입력하거나 생성하지 않았다. 실제 사용 시 교사가 성취 수준과 문장 내용을 검토해야 한다.
